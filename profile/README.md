## Social Ecosystem (Freedom and privacy)

**Magpie** 是一个去中心化的社交网络，旨在捍卫自由和隐私。

## 🚩 项目使命 (Our Mission)
* 在中心化的数字世界中，旨在打破数据孤岛，抵抗审查。
* 打造一个用户控制身份、拥有数据且言论自由的数字公共广场。

## 🌟 核心价值观 (Our Core Values)
* **自由 (Freedom)**：捍卫言论自由，设计抗审查的网络。
* **隐私 (Privacy)**：严格遵守高标准的隐私保护，用户完全掌控数据。
* **去中心化 (Decentralization)**：通过自托管和 P2P 技术，确保无单一实体控制网络。
* **平等 (Equality)**：包容所有身份和表达。

## ✨ 核心功能 (Core Features)
* **🛡️ 安全通信**：端到端加密 (E2EE)、消息送达保证、离线存储。
* **🔐 数据主权与隐私**：支持自托管节点、去中心化备份、标签与排序。
* **🌐 抗审查**：P2P 网络架构、客户端屏蔽/过滤功能（而非平台级审查）。
* **💬 完整的社交体验**：1对1及群组聊天、二手市场、插件支持。

## 🌍 跨平台支持 (Cross-Platform Support)
覆盖以下平台：
* **桌面端**：Windows, macOS, Linux
* **移动端**：Android, iOS
* **Web 端**：所有现代浏览器

## 🛠️ 架构与技术栈 (Architecture & Tech Stack)
核心是去中心化 P2P 协议，涉及多种技术：
* **前端/客户端**：Vue/React, Node.js, TypeScript, Kotlin, Swift, Flutter, Electron, .NET
* **后端/服务**：Java, Python, Go, C++, C#
